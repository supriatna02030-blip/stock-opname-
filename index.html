📖 Tutorial Cara Pakai

🔐 1. Login

Masukkan NIK dan PIN yang sudah terdaftar. Admin awal: ADMIN / 1234.

🏠 2. Daftar Ruang SO

Buat ruang baru sesuai kebutuhan, misalnya SO RAHIL A, SO RAHIL B, atau ruangan tertentu.

📦 3. Input Barang

Gunakan tombol Load 43 Item untuk memuat template. Kamu juga dapat menambahkan produk secara manual.

📷 4. Scan Barcode

Tekan tombol kamera lalu arahkan kamera ke barcode. Jika kode ditemukan, jumlah Fisik otomatis bertambah 1.

📋 5. OH Shift Sebelumnya

Pada Shift 2 atau Shift 3, gunakan tombol Ambil OH untuk mengambil Fisik dari shift sebelumnya.

📊 6. Rekap Minus & Plus

Minus berarti Fisik lebih kecil dari OH. Plus berarti Fisik lebih besar dari OH. Nilai rupiah dihitung berdasarkan harga barang.

📲 7. Kirim WhatsApp

Dari menu Laporan, gunakan WA Minus atau WA Plus. Aplikasi akan membuat pesan otomatis.

💾 8. Backup Data

Gunakan Backup Semua Data secara berkala agar data tetap aman jika perangkat bermasalah.

🎨 9. Tema

Pilih salah satu tema warna profesional. Tema tersimpan otomatis di perangkat.
