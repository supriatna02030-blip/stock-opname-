📖 Tutorial

👉 Buka Tutorial Lengkap

Login: gunakan NIK dan PIN terdaftar. Admin awal: ADMIN / 1234.

Ruang SO: buat ruang, buka ruang, lalu Load 43 Item atau tambah produk manual.

Opname: OH adalah stok sistem, Fisik adalah hasil hitung. Selisih otomatis dihitung.

Barcode: tombol kamera akan menambah Fisik +1 jika kode ditemukan.

Shift: simpan tiap shift dan gunakan Ambil OH Sebelumnya untuk melanjutkan.

Laporan: tersedia Minus, Plus, WhatsApp, CSV dan PDF.

Backup: lakukan backup JSON secara berkala karena data tersimpan lokal di browser.
