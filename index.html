📖 Tutorial Penggunaan

👉 Buka Tutorial Lengkap

🔐 1. Login

Masukkan NIK dan PIN yang sudah terdaftar. Admin awal:
NIK: ADMIN
PIN: 1234

🏠 2. Daftar Ruang SO

Buat ruang SO sesuai kebutuhan. Misalnya: SO RAHIL A, SO RAHIL B, MINYAK, GULA, dan sebagainya.

📦 3. Input Barang

Buka ruang lalu tekan Load 43 Item untuk memasukkan template barang. Kamu juga bisa menambahkan produk secara manual.

📷 4. Scan Barcode

Tekan tombol kamera lalu arahkan kamera ke barcode. Jika kode ditemukan, nilai Fisik akan otomatis bertambah 1.

📊 5. OH & Fisik

OH = stok menurut sistem.
Fisik = stok hasil perhitungan langsung.
Selisih otomatis dihitung oleh aplikasi.

❌ 6. Minus

Jika Fisik lebih kecil daripada OH, barang masuk kategori Minus dan nilai kerugian dihitung berdasarkan harga.

✅ 7. Plus

Jika Fisik lebih besar daripada OH, barang masuk kategori Plus.

📋 8. Rekap

Menu Laporan menampilkan barang Minus, Plus dan total nilai selisih.

📲 9. WhatsApp

Tersedia tombol untuk mengirim:
❌ Rekap Minus
✅ Rekap Plus
📋 Rekap Semua

📑 10. PDF & CSV

Gunakan PDF untuk laporan dan CSV untuk backup atau dibuka menggunakan Excel.

☕ 11. Rehat Sejenak

Gunakan fitur ini ketika sudah terlalu lama melakukan SO. Tersedia animasi, latihan napas, timer, partikel dan suara relaksasi yang dibuat langsung menggunakan JavaScript.

💾 12. Penyimpanan

Data disimpan di penyimpanan browser perangkat. Gunakan menu Backup secara berkala agar data lebih aman.
